## 1. 这个系统是做什么的？

简单说：**你用日常说话的方式提问，AI 帮你找答案、做计算，甚至直接帮你查数据库。**

过去想从数据库里查数据，需要懂 SQL（一种数据库查询语言），还要找技术同事帮忙。现在你只需要像发微信一样输入一句话，例如：

> "统计近三个月各类别的数据量"

系统会自动理解你的意思，写好查询语句、查出数据，并用表格和图表展示结果。

系统内部有几位各有所长的"智能体"（可以理解为不同专长的 AI 助手），提问时系统会自动把问题交给最合适的那一位：

| 智能体 | 它擅长什么 | 举个例子 |
|--------|-----------|----------|
| **General**（通用助手） | 日常问答、数学计算、联网搜索、查知识库 | "帮我算一下 10 万元年化 3% 存 5 年的复利收益" |
| **SQL**（查数助手） | 把你的话翻译成数据库查询，返回表格和图表 | "统计近三个月各类别的数据量" |
| **Code**（代码助手） | 代码相关问答（**开发中，暂不可用**） | — |

你还会在界面上频繁看到这两个词，先认识一下：

- **模型（Model）**：驱动 AI 回答的"大脑"，不同模型能力和速度略有差别。不确定选哪个就用默认的。
- **Agent（智能体）**：上表中的助手类型。日常问答选 General，查数据选 SQL。

放心使用的三个理由：

- **过程看得见**：AI 先展示"思考过程"，再给出正式回答，不是黑盒；
- **数据安全**：所有查询默认只读，任何可能修改数据的操作都必须经过人工审批；
- **能聊多轮**：同一个对话里可以追问，比如先问"近三个月销量"，再接着问"那上个月呢"，AI 能听懂。

## 2. 使用 API Key

有两种方式，按需选择其一：

### 2.1 方式一：系统模型的个人 Key（联系管理员）

模型设置里的"系统模型"是管理员统一维护的，普通用户只能查看。如果想用**自己的额度**调用这些系统模型，请**联系管理员**为你的账号绑定个人 API Key。绑定成功后，对应模型会显示"已配置密钥"标记，之后的调用将自动走你自己的 Key 计费（2000RMB/人）。

### 2.2 方式二：自建 Provider（自助配置）

**第一步：到模型厂商官网申请 API Key**

API Key 相当于你在厂商那里的"充值卡密码"。前往厂商的开放平台 → 注册账号 → 找到"API 密钥 / API Keys"页面 → 创建并**立即复制保存**密钥（通常形如 `sk-...`，只在创建时显示一次）：

| 厂商 | 开放平台网址 |
|------|--------------|
| SiliconFlow | cloud.siliconflow.cn |
| OpenAI | platform.openai.com |
| DeepSeek | platform.deepseek.com |
| OpenRouter | openrouter.ai |
| 阿里 DashScope | dashscope.console.aliyun.com |
| 智谱 AI | open.bigmodel.cn |

**第二步：回到系统里填入**

1. 点击侧边栏的**设置齿轮**，打开"模型设置"；
2. 点击 **添加 Provider**，从快捷模板中选择你的厂商（系统会自动填好服务地址），然后粘贴你的 **API Key**，并起一个自定义名称（如 `my-deepseek`）；
3. 在该 Provider 下**添加模型名**——注意必须与厂商官网上的模型 ID 一字不差（如 `deepseek-chat`），可以添加多个；
4. 点击**保存**。系统会自动测试连接：失败会提示具体原因（如 Key 无效、地址错误），测试通过才会真正保存；
5. 保存成功后，你的模型就会出现在输入框 **Model 选择器的 "Custom" 分组**里，也可以在模型设置中把它设为**默认模型**。

> 名称、服务地址、API Key 三项都是必填的。以后想修改或删除，同样在"模型设置"对话框里操作。

## 3. 登录系统

在浏览器中打开管理员提供的系统网址，页面会自动跳转到登录页。

### 3.1 推荐方式：使用 CUHK SSO 登录

如果你有 CUHK 统一账号，这是最简单的登录方式——**不需要注册，点一下就能用**：

1. 在登录页点击 **使用 CUHK SSO 登录**（Sign in with CUHK SSO）按钮；
2. 页面会跳转到 CUHK 的统一身份认证页，输入你的 CUHK 账号和密码完成认证（如果浏览器里已登录过 CUHK 其他系统，这一步可能自动通过）；
3. 认证成功后自动跳回本系统，直接进入聊天主界面。

**首次登录会自动为你创建账号**，无需任何额外操作；之后每次都用同一个按钮登录即可。

> SSO 登录的账号密码由 CUHK 统一管理，本系统不保存你的 CUHK 密码。忘记密码请走学校的密码找回渠道。

### 3.2 备用方式：邮箱注册与登录

没有 CUHK 账号？也可以用邮箱自行注册：

1. **注册**：在登录页点击 **注册**（Register）链接，填写 **Email**、**密码**（至少 6 位）、**确认密码**，勾选用户条款后提交；
2. **登录**：回到登录页，输入 Email 和密码，点击登录即可进入主界面。

> 为了安全，登录每分钟最多尝试 5 次。密码连续输错时请稍等片刻再试。

**忘记邮箱密码**：在登录页点击 **忘记密码**，输入注册邮箱，系统会发送密码重置邮件；一直收不到邮件请联系管理员后台重置。（此功能仅针对邮箱账号，SSO 账号请走学校渠道。）

### 3.3 退出登录

点击侧边栏底部的 **登出** 按钮即可退出。使用 CUHK SSO 登录的用户，登出时会同步退出 CUHK 统一登录会话。

## 4. 认识主界面

登录后看到的聊天主页分为三块：

```
┌──────────┬──────────────────────────┐
│          │                          │
│  侧边栏   │        对话区             │
│          │   （问题和回答都在这里）     │
│          │                          │
│          ├──────────────────────────┤
│          │        输入框             │
└──────────┴──────────────────────────┘
```

**左侧边栏**（可点击按钮折叠）：

| 位置 | 功能 |
|------|------|
| 顶部 | **New Chat**：开启一个全新对话（换新话题时记得点它） |
| 中部 | **提示词库**面板（见[第 8 节](#8-提示词库让-ai-按你的风格回答)） |
| 底部 | 你的**头像**（点击修改资料）、**用量统计**、**设置齿轮**、**登出** |

**底部输入框**：打字提问的地方。右下角有三个下拉选择器：

| 选择器 | 什么时候需要动它 |
|--------|------------------|
| **Model** | 一般保持默认即可；想换"大脑"时再选 |
| **Agent** | 日常问答选 **General**；要查数据库时切到 **SQL**（Code 是灰色的，暂未开放） |
| **Database** | 只有用 SQL 助手时才需要：选择你要查询的目标数据库 |

**右上角**：可随时切换 **中文 / English** 界面语言，以及 **明亮 / 暗黑** 主题，点一下立即生效。

## 5. 开始第一次对话

### 5.1 提个问题试试

1. 确认输入框右下角 Agent 是 **General**（默认就是）；
2. 在输入框里打一句话，比如："帮我算一下 10 万元年化 3% 存 5 年的复利收益"；
3. 按回车（或点发送按钮）。

### 5.2 回答会分几段出现

AI 的回答不是一下子蹦出来的，而是按顺序"打字机式"地逐段展示：

1. **意图标签**：系统先告诉你它把问题交给了哪位助手；
2. **思考过程**：AI 的推理草稿，默认展开，可以折叠收起，也可以复制；
3. **工具调用卡**（不一定有）：如果 AI 用了计算器、联网搜索等工具，会显示一张小卡片；
4. **正式回答**：真正的答案，支持标题、列表、表格等排版；
5. **Token 统计**：本次回答消耗的用量（可以不用关心）。

### 5.3 对话中的常用小操作

- **追问**：直接在同一对话里继续输入，AI 记得前文。比如先问"北京的人口"，再问"那上海呢"；
- **停止生成**：AI 回答太长不想等了？点一下停止按钮立即中断；
- **重新回答**：对回答不满意，点你那条提问旁的 **Regenerate**，AI 会按当前设置重答一次；
- **点赞 / 点踩**：每条回答下方有 👍 / 👎 按钮，点 👎 还可以写下具体意见，帮助系统改进；
- **换话题**：聊新话题前，建议点侧边栏 **New Chat** 开新对话，避免 AI 被旧话题带偏。

> 提问频率限制为每分钟 20 次，正常使用完全够用。

## 6. 用一句话查数据库

这是本系统最有特色的功能：**不写一行代码，就能查数据库。**

### 6.1 操作步骤

1. 在输入框右下角把 **Agent** 切换为 **SQL**；
2. 在 **Database** 选择器里选好要查的数据库（不知道选哪个可以问管理员）；
3. 用自然语言描述你想查什么，例如：
   - "统计近三个月各类别的数据量"
   - "销量最高的前 10 个产品是哪些"
   - "每个月的新增用户数，按月份列出来"
4. 回车发送，等待结果。

### 6.2 正常情况：直接出结果

如果你的问题是普通的"查询"（只读数据、不改数据），系统会直接执行，并依次展示：

1. **SQL 解释气泡**：用大白话告诉你"这条查询在做什么"，方便你确认 AI 理解对了没有；
2. **表格和图表**：查询出的数据；
3. **文字总结**：AI 对结果的简要解读。

### 6.3 特殊情况：弹出"审批面板"

如果 AI 生成的操作**可能修改数据**（比如更新、删除），或涉及受保护的数据表，系统**不会擅自执行**，而是弹出一个 **SQL 审批面板**，把将要执行的语句和含义摆在明面上，由人来决定：

| 按钮 | 含义 |
|------|------|
| **Approve** | 确认没问题，批准执行，结果随后返回 |
| **Regenerate** | 不执行这条，让 AI 重新生成 |
| **Cancel** | 取消这次操作 |

审批请求会实时推送给有权限的审批人。即使你刷新了页面，待审批的任务也不会丢失。

> 对普通用户来说，日常"查数据"的问题几乎都会直接放行，很少触发审批。遇到审批面板不用慌，它正是系统在保护数据安全。

### 6.4 红色告警：查询被拦截

如果你的请求命中了危险操作或受保护的数据表，系统会直接拒绝，并用**红色告警卡**显示拦截原因。这是正常的安全机制，不是故障；如果你确实有相关业务需要，请联系管理员。

## 7. 看懂查询结果：表格、图表与导出

### 7.1 表格

- 查询结果以表格展示，页面上最多加载前 **512 行**，表格会标注实际总行数；
- 点表格右上角的 **Export CSV**，即可把当前已加载的数据下载为 CSV 文件（可用 Excel 打开）。

> 如果数据量很大、需要导出完整结果，请联系管理员获取（最多支持 1 万行，xlsx 或 csv 格式）。

### 7.2 图表

当查询结果适合画图时，系统会**自动生成图表**，并说明推荐这种图的理由：

- 支持 **柱状图、折线图、饼图、面积图、散点图** 五种类型；
- 觉得默认图不合适？可以手动切换图表类型；
- 图表和表格之间可以随时互相切换查看。

## 8. 提示词库：让 AI 按你的风格回答

如果你希望 AI 每次都按某种固定风格或要求回答（比如"回答一律用简体中文、先给结论再给理由"），可以把这些要求写成一个 **提示词文件**，让系统每轮对话自动带上。

在侧边栏打开**提示词面板**：

1. **上传**：点回形针按钮，上传一个 `.md` 格式的文本文件（用记事本写好要求，另存为 `.md` 后缀即可）；
2. **激活**：点击某条提示词把它设为"激活"状态——同一时间只有一条生效，之后每次提问都会自动附带它；
3. **管理**：每条提示词都支持预览、改名、编辑、删除；
4. **临时取消**：激活的提示词会以**小徽标**显示在输入框上方，某一轮不想带它时，点徽标上的 **×** 即可仅本轮取消（不会删除，下轮恢复）。

## 9. 查看用量与修改个人资料

### 9.1 用量统计

点击侧边栏的**用量统计**按钮，可以查看自己最近 **7 / 30 / 90 天**的使用情况：

- 请求次数、总 Token 数、花费金额（USD）；
- 按日柱状图（可在 Tokens / Cost 之间切换）；
- 按模型分类的用量明细。

> 管理员可能为账号设置了**每月花费上限**，超出后新请求会被拒绝。如遇到"配额不足"提示，可联系管理员调额(smeit@cuhk.edu.cn)。

### 9.2 个人资料

点击侧边栏底部的**头像**，可以：

- 上传新头像（支持 JPEG / PNG / WebP / GIF，不超过 2MB）；
- 修改自己的显示名称。

## 10. 常见问题 FAQ

**Q1：提示"请求过于频繁"怎么办？**
提问每分钟最多 20 次，登录每分钟最多 5 次。稍等一分钟再试即可。

**Q2：发出问题后一直停在"思考中"？**
先换一个模型试试。如果你用的是自建模型，打开"模型设置"重新保存一次（会自动测试连通性），根据报错提示排查；如果用的是系统模型仍然失败，请联系管理员。

**Q3：为什么我的查询弹出了审批面板，或被红色告警拦截？**
普通"查数据"会直接执行；可能修改数据的操作需要人工审批；危险操作或涉及受保护数据表会被直接拒绝。这些都是系统的正常安全机制，详见[第 6 节](#6-用一句话查数据库)。

**Q4：Code Agent 为什么是灰色不能选？**
该功能还在开发中，暂未开放。

**Q5：以前的聊天记录在哪里看？**
当前版本不提供历史会话列表。同一个对话内的上下文会自动保持；开始新话题时建议点 **New Chat**。

**Q6：提示"配额不足"怎么办？**
说明本月花费已达到管理员设置的上限。可以在"用量统计"里查看具体花费，然后联系管理员调额(smeit@cuhk.edu.cn)。

**Q7：导出的 CSV 行数不全？**
页面上的 **Export CSV** 只导出已加载的前 512 行。需要完整数据（最多 1 万行）请联系管理员导出。

**Q8：CUHK SSO 登录报错怎么办？**
登录页的提示条会显示具体原因。常见情况：授权超时（重试即可）、回调地址不一致（请联系管理员核对配置）；CUHK 账号或密码问题请走学校的统一身份认证支持渠道。

**Q9：上传提示词文件失败？**
请确认文件是 `.md` 格式（纯文本，后缀为 .md）。用记事本或任意文本编辑器编写内容后，另存为 `.md` 后缀即可。

**Q10：AI 答非所问怎么办？**
试试这三招：① 把问题描述得更具体（时间范围、对象、想要的形式）；② 点 **Regenerate** 重答；③ 换新话题时先点 **New Chat**，避免被旧对话干扰。
