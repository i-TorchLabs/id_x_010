实现如下要求:

[技术栈]
服务端: Python + Quart Framework
数据库: PostgreSQL + PgVector
大语言模型: LangGraph + LangChain + SemanticRouter

[功能点]
1. 智能问答系统, 后台调用 OpenRouter 的 API
2. 使用异步函数和异步编程
3. 支持异步任务的并发执行
4. 支持模型的切换
5. 支持"本地模型"和"外部模型"的切换
6. 服务端以流式响应
7. 客户端以流式接收
8. 记录思考过程

[项目/目录结构]
1. id_x_000/main.py  启动文件
2. id_x_000/config/base_config.toml  配置文件
3. id_x_000/src/adapt.py  接入文件: 负责根据“配置文件”中“MODELS”的定义, 导入"/id_x_000/x_models/"下的模块
4. id_x_000/x_models/id-x-010  模型目录: 包含所有模型的实现具体代码
5. id_x_000/x_models/id-x-010/src/agents/x_semantic_router.py  语义路由器: 负责根据用户输入的自然语言, 路由到合适的模型
6. id_x_000/x_models/id-x-010/src/agents/x_orchestrator.py  编排器: 负责基于 LangGraph 构建 StateGraph 状态机
7. id_x_000/x_models/id-x-010/src/agents/x_general_agent.py  通用代理: 负责将用户输入的自然语言转发给其他模型处理
8. id_x_000/x_models/id-x-010/src/controllers/x_controller.py  控制器: 定义 GraphQL 的各种接口
9. id_x_000/x_models/id-x-010/src/models/x_model.py  模型: 定义PostgreSQL数据库的模型和字段
10. id_x_000/x_models/id-x-010/src/schemas/x_schema.py  模式: 定义 GraphQL 的数据模式
11. id_x_000/x_models/id-x-010/src/views/x_view.py  视图: 定义 GraphQL 的各种查询和变更接口, 以及其他业务逻辑

[核心交互流程描述]
1.  **接收用户请求**: 监听 0.0.0.0:18080
2.  **网关接入**: Quart 接收请求
3.  **意图识别**: Semantic Router 分析语义，判定为“常规查询意图”，将请求转发给 **General Agent**
4.  **模型推理**: General Agent 构造 Prompt，通过模型切换器调用不同大模型, 并获取“思考过程”和“反馈结果”
6.  **响应返回**: 结果经由 Quart 流式返回给前端展示
