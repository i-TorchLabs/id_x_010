>
> 编号 id_x_010 · 研发主体 TorchLabs · 协议 AGPL-3.0

## 一、为什么需要它（痛点）

政府与科研单位在数据治理与知识服务上长期面临三难：

| 难点 | 现状 | 后果 |
| --- | --- | --- |
| **查数难** | 业务人员看不懂 SQL，依赖 IT 部门排期 | 决策滞后，数据价值无法释放 |
| **管数险** | 直接开放数据库给大模型，存在越权、注入、泄露风险 | 合规红线不可触碰 |
| **溯源空** | AI 给出结论却无过程、无证据 | 决策不敢用、不敢信 |

id_x_010 正是为解决上述三难而生：**用自然语言查数，用安全白名单管权，用思考流留痕溯源**。

---

## 二、它是什么（产品定位）

一个可插拔的**智能体编排插件**，挂载于 i-Core 主程序，对外提供 GraphQL + SSE 双通道服务，内置三类智能体：

- **General Agent**：通用问答 + 工具调用（计算器、联网搜索、知识库检索）
- **SQL Agent**：自然语言 → SQL → 执行 → 自然语言回答，含白名单与人工审批
- **Code Agent**：代码生成与解释

核心交互：用户说"查近三个月的实验数据" → 系统自动识别意图 → 生成 SQL → 安全校验 → 执行 → 用自然语言回答"近三个月共有 1,284 条实验记录…"。

## 三、五大核心能力

### 1. 双路由意图识别 —— 准而快

- **Semantic Router** 毫秒级命中高频意图（向量相似度匹配）
- **LLM Router** 兜底长尾问题（推理级判定）
- 两层协同，误判率显著降低，避免"查数请求被当成闲聊"

### 2. SQL 安全白名单 + 人工审批闭环 —— 管得住

- SQL 语句执行前经**白名单静态校验**，仅允许 SELECT 等安全操作
- 越权或高危语句自动**挂起并推送人工审批**，审批通过后方可执行
- 目标库与业务库**物理隔离**，连接配置统一存放于 `agent_db_settings` 表，杜绝越库访问
- 受保护表清单（`PROTECTED_TABLES`）屏蔽敏感表

### 3. 知识增强检索（RAG）—— 查得准

- 基于 pgvector 向量索引数据库 Schema 与文档片段
- 用户提问时只召回 Top-N 相关表结构，避免 Token 溢出
- SQL 生成准确率大幅提升，告别"把全库 schema 塞给大模型"的粗放模式

### 4. 思考过程分离流 —— 可溯源

- 推理链路与最终答案通过**独立 SSE 事件流**推送
- 前端分区展示"思考中"与"回答中"两种状态
- 每一次回答都伴随可回放的状态流转，**决策有据可查**

### 5. 模型配置热回退 —— 用得稳

- 模型配置支持热更新与失败自动回退
- 支持**本地模型**（Ollama / vLLM 部署 Qwen、Llama 等）与**外部模型**切换
- 本地模型保障数据不出域，满足涉密场景合规要求

## 五、典型应用场景

1. **政务数据自助查询**：业务处室用自然语言查询统计报表，无需提工单等排期
2. **科研知识库问答**：科研人员向文档库提问，系统检索相关片段并生成引用
3. **数据安全审查**：高危 SQL 自动挂起审批，审批人一键放行或驳回
4. **多轮对话分析**：支持上下文追问，"这个表"指代自动消解，长对话不丢关键信息
5. **实时数据看板背后的问答引擎**：作为数据中台的智能问答层嵌入

## 六、技术架构（八层分层）

```
L1 表示层  Next.js 16 + React 19 + HeroUI + Tailwind 4
L2 网关层  HAProxy 分流 / 负载均衡

```

## 七、安全合规设计

- **三权分立**：业务库（存对话日志）与目标库（存业务数据）物理隔离，SQL Agent 仅持只读连接
- **白名单静态校验**：SQL 执行前拦截非 SELECT、非白名单表、危险函数
- **人工审批闭环**：高危语句挂起 → 推送审批人 → 审批通过方可执行 → 全程留痕
- **本地模型支持**：涉密场景切换本地大模型，数据不出政务网络
- **限流与配额**：进程内滑动窗口限流 + 用户日 token 配额，防止滥用与账单失控

## 八、部署与落地

- **一键容器化部署**：`bash ops/up.sh` 启动全部服务（含 HAProxy 分流）
- **环境要求**：Python 3.11+ / Node.js 20+ / PostgreSQL 14+（含 pgvector 扩展）
- **国产化适配**：基于开源技术栈，可部署于信创环境；支持麒麟、统信等国产 OS 上的 Docker 运行时
- **实施周期**：单场景落地 2-4 周（含 Schema 索引构建、Few-Shot 例子库、权限对接）
