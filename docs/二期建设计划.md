## 二、一期情况与主要问题

AI智能体为SME核心架构业务插件，一期已具备多智能体编排、SQL 安全审批、流式对话及模型计价配额等能力，主链路可用。详见 [一期能力摘要](../../../docs/sources/id-x-010-phase1-capability-excerpt.md)、[能力缺口对照](../../../docs/sources/id-x-010-phase1-capability-gap.md)。

依据 [用户反馈](../../../docs/sources/id-x-010-phase2-user-feedback.md)，当前突出问题如下：

| 问题 | 主要表现 |
| --- | --- |
| 历史会话 | 缺少保存、加载与列表回看 |
| 费用展示 | 用户侧价格与费用说明不清晰 |
| Code Agent | 代码能力偏弱，未形成可验收模块 |
| 图片 OCR | 专用文字识别与结果回流不足 |
| 长文本 Prompt | 长规范、长模板易截断或失败 |

费用清单纳入历史会话模块落实，长文本 Prompt 随 OCR 与提示词链路一并改进。二期在一期框架上补齐短板，投入可控，便于组织实施。

## 三、建设方案

### （一）OCR 识别模块

**目标**：支持图片（截图、扫描件）上传与文字识别，结果可注入对话及提示词；完善校对、轻量结构化抽取及失败处理。

**验收**：常见中文材料识别可用；识别结果可保存、可再次打开。

### （二）历史会话模块

**目标**：建成会话列表、打开恢复、归档检索；按用户隔离，支持续聊与检索；同步展示模型单价、本次及累计费用、配额进度。

**验收**：可便捷找回并续聊；费用依据清楚。

### （三）Code Agent 模块

**目标**：形成独立可验收能力——需求理解、代码生成与解释、受控执行及结果回传；明确与通用、SQL 智能体的边界及安全策略。

**验收**：评测任务达标；高风险操作可控。
